# Speakeys releases

This repository only hosts installer files for **Speakeys**, voice typing and AI editing for macOS.
Source code is not published here.

- Download the latest version: [Speakeys.dmg](https://github.com/kameel77/speakeys-releases/releases/latest/download/Speakeys.dmg)
- Website and documentation: [speakeys.app](https://speakeys.app) · [docs](https://speakeys.app/docs/)
- Support: hello@finarena.pl

Releases are published from the app repository with `./build.sh release`. The asset must always be named `Speakeys.dmg`,
because the website links to `releases/latest/download/Speakeys.dmg`.
